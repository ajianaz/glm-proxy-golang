# Project Rules

## Git Workflow

- **SELALU konfirmasi sebelum commit dan push.** Jangan commit atau push tanpa persetujuan user.
- Jelaskan dulu apa yang akan di-commit, lalu tanya "mau di-commit dan push?"
- Jangan langsung commit apalagi push ke main tanpa konfirmasi.
- Untuk perubahan besar, buat branch dan PR — bukan langsung ke main.
